# 界面提升（浅色主题）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在不改变信息架构和三栏布局的前提下，修复 UI bug、统一控件体系、补齐空状态引导、贯通评分/标签/旗标元数据到界面，让浅色主题下的 Photo Tool 达到视觉一致、无死路的可用状态。

**架构：** 全部改动在 `photo-tool-app/src/ui/` 的纯渲染函数内进行，新建 `ui/controls.rs` 承载共享控件（分区标题、分段按钮、清除链接）。唯一涉及 core 的改动是任务 10：`CaptureMeta` 增加 3 个元数据字段 + `enrich_with_xmp()`，遵循现有 `enrich_with_exif` 的延迟填充模式。主题锁定浅色（`ThemeMode::Light`），不改 `theme.rs` 调色板。

**技术栈：** Rust nightly / edition 2024、GPUI（zed-industries）、gpui-component（Button / Rating / Icon / StatusBar）、photo-tool-core（domain / xmp / scanner）。

**验证策略：** GPUI UI 无测试设施，UI 任务验证 = `cargo build -p photo-tool-app` + `cargo clippy --all-targets` + 人工视觉 checklist；core 变更（任务 10）走 TDD，`cargo test -p photo-tool-core`。

## 视觉基准（设计决策锁定）

1. **主题**：浅色锁定。accent 唯一：蓝 `text_accent`（#3b82f6），用于选中边框、聚焦态。
2. **层次**：中央/面板底色 `background`（#f3f4f6），卡片/工具栏/状态栏 `surface_background`（白）。当前右侧面板与卡片同为白色导致无层次，任务 7 修复。
3. **圆角体系**：卡片/按钮 `rounded_md`（6px），指示点/圆形箭头 `rounded_full`，输入框 `rounded_sm`。不混用。
4. **图标**：一律 `gpui_component::IconName`，禁止 unicode 符号字符（★ ☆ ◀ ▶ ✕ − ＋ ⇕ 全部替换）。已确认 assets 中存在：`ChevronLeft/Right`、`Star/StarFill`、`Minus`、`Plus`、`Frame`、`Close`、`FolderOpen`、`Search`、`Settings`、`File`、`LayoutDashboard`、`SortAscending`、`Redo2`、`GalleryVerticalEnd`。
5. **分区标题**：全应用一个组件（`controls::section_header`），粗体 xs muted，删除 info_panel 自带的 hairline 版本。
6. **空状态**：每个空态必须有主动作按钮或明确占位文案，禁止死路引导。
7. **按钮体系**：工具栏/面板内默认 `ghost + icon + label`；主动作唯一 `primary`（「导入」）；分段选择用 `ghost + selected` 小按钮组。

/// 分区标题：全应用统一的 section header（粗体 xs muted）。
pub fn section_header(label: &str) -> Div {
    div()
        .font_weight(FontWeight::SEMIBOLD)
        .text_xs()
        .text_color(theme::colors().text_muted)
        .pb_1()
        .child(label.to_string())
}

/// 分段选择按钮：用于「任意/入选/淘汰/未标记」这类互斥选项组。
pub fn segmented_button(
    id: impl Into<ElementId>,
    label: &str,
    active: bool,
    on_click: impl Fn(&ClickEvent, &mut Window, &mut App) + 'static,
) -> Button {
    Button::new(id)
        .small()
        .ghost()
        .selected(active)
        .label(label)
        .on_click(on_click)
}

/// 小号清除入口：替代全宽 ghost 按钮，右对齐放置。
pub fn clear_link(
    id: impl Into<ElementId>,
    label: &str,
    on_click: impl Fn(&ClickEvent, &mut Window, &mut App) + 'static,
) -> Button {
    Button::new(id)
        .small()
        .ghost()
        .label(label)
        .on_click(on_click)
}

    /// 从 XMP 旁车文件填充评分/颜色标签/旗标（轻量调用：只读 sidecar）
    pub fn enrich_with_xmp(&mut self) {
        if !self.has_xmp {
            return;
        }
        let xp = crate::xmp::xmp_path(std::path::Path::new(&self.primary_path));
        if let Ok(meta) = crate::xmp::read_xmp(&xp) {
            self.rating = meta.rating();
            self.color_label = meta.color_label();
            self.flag = meta.flag();
        }
    }
